# Search Parameters

This document classifies all search parameters in LibraAI.

| Parameter | Source | Hard/Soft | Persistent | Purpose |
|-----------|--------|-----------|------------|---------|
| query | User/AI | Retrieval | No | Search intent |
| availability | User | Hard | No | Library availability (`available_only`) |
| category | User/AI | Hard | No | Topic filter |
| difficulty | User/AI | Hard | No | Level |
| department | Profile | Soft/Hard if explicit | Yes | Academic context |
| semester | Profile | Soft | Yes | Academic context |
| course | Profile/User | Soft | Current | Course relevance |
| interests | Profile | Soft | Yes | Personalization |
| history | System | Soft | Yes | Behavioral relevance |
| popularity | System | Soft | No | General relevance |
